# NB 输入法：热词里的「一定替换」

2026-10-29。PM 想在热词里写「一定会把某个词换成另一个词」。

## 拍的板

- 写法用等号，不用箭头（键盘不好打）：`日色=润色`，几种错法用顿号隔开：`Clochat、Claw Chat=ClawChat`。全角 `＝` 也认，`->`、`→`、`=>` 照样认但不写进示例。
- 热词页顶上只放两行示例，不写长句子：`Wan3` 常用词，`日色、日社=润色` 一定替换。

## 做法（`Replace.swift`）

- 补的是读音纠正（`Hotfix`）管不到的：读音不一样的错（日色 / 润色、表粗打细 / 表达），拆不成拼音的英文词（Clochat / ClawChat）。
- 识别结果出来先按规则替换，再按读音换回热词，再润色；说话时的实时预览也走同一套。日志记「按规则替换：日色→润色」。
- 等号右边的词自动算热词（交给模型、读音纠正、润色保留）；左边的错词不交给模型。
- 规矩：左边至少两个字（一个字到处误换，写了也不生效，热词页底下会提示「1 条没生效」）；英文两头按整词算、不分大小写（`Clochat` 不会把 `Clochats` 拆开换）；长的先匹配；只换一遍，不会 A→B 再 B→C。
- 写了等号但不生效的行不当普通热词。
- 热词文件格式不变，一行一条；`Settings.hotwordLines()` 是原样的行（热词页编辑的），`hotwordList()` 是生效的热词（普通的行加规则右边的词），`replaceRules()` 是规则。

## 实测

- 单独测替换：日色→润色、clochat / Claw chat→ClawChat、Clochats 不换、表粗打细→表达、甲乙→丙丁 和 丙丁→戊己 不连锁、日色彩=色彩 比 日色=润色 优先、「张=李」不生效。
- 整条流程：临时加「李总=王总」，`--test-file` 跑合成语音「把合同发给李总……」，输入的是「把合同发给王总……」，日志有「按规则替换：李总→王总」。测完热词文件还原。
