# 「更正一下」变「更+1下」、「Agent」变「A 帧」、两句粘在一起

2026-11-01。PM 说「更正一下，谁说轻量 Agent 不能上网了」，输出「更 +1下，谁说轻量 A 帧的不能上网了？」，重说了三次都一样。另外反映：上一句末尾没标点时，接着输入的下一句会和它连在一起。

## 一、「正一」被转成「+1」

预览是对的（「先更正一下」），完整结果才错。ITX 上 CapsWriter 的 `format_num = True` 会把中文数字转成阿拉伯数字（`core/tools/chinese_itn`），它的正则是 `[正负]?` 加数字：只要「正」「负」后面跟着数，就当成正负号。拿它的代码在本机跑：

| 原话 | 转完 |
|---|---|
| 先更正一下 / 改正一下 / 纠正一下错误 | 先更+1下 / 改+1下 / 纠+1下错误 |
| 反正一样 / 纠正两个问题 / 改正十几个 | 反+1样 / 纠+2个问题 / 改+10几个 |
| 修正一个bug / 他欺负一个小孩 | 修+一个bug / 他欺-一个小孩（数没转，号转了） |
| 不要辜负一番好意 / 胜负一目了然 | 不要辜-1番好意 / 胜-1目了然 |
| 零下负二十度 | 零下-20度（这个是对的） |

**改法**：客户端新加 `Signfix.swift`，拿到完整结果先过一遍：「+」「-」前面一个字和「正」「负」能连成常用词（更正、纠正、真正、反正……欺负、辜负、胜负……）的，换回「正」「负」，后面紧跟的数也换回汉字（一百以内照读法，「2」后面跟量词读「两」，小数逐位读）。不在词表里的不动，所以「零下-20度」「C++1」「v-1.2」照旧。日志记「正负号换回字：… → …」。

没改 ITX 上的 CapsWriter：一是改 ITX 要先问 PM，二是照 `setup-with-agent.md` 搭的人用的也是原版 CapsWriter，客户端修了大家都受益。

## 二、「Agent」听成「A 帧」

拿当时存下的三段录音重放给服务端，每段 3 次：

- 热词表不变：「轻量 A 帧的」3 次里 3 次（第三段）、2 次（第二段）。
- 热词里加上「Agent」：第三段还是 3 次都是「A 帧」，第二段变成「Agent 的 / A 柜的 / Agent」。热词提示压不住。

所以在 PM 的热词里加了一条一定替换 `A帧、A 帧=Agent`（右边的 Agent 自动算热词）。服务端会在字母和汉字之间加空格，所以两种写法都写上。

## 三、润色把「先更正一下」当改口删了

修好第一条以后，「先更正一下，我觉得你是不是？」在去口误中档时每次都被删成「我觉得你是不是？」——以前是「更+1下」，模型没认出来，反而留着。

- 先试了改提示词（改口那条后面加「开头说的『先更正一下』是要打出来的话，照留」）：这一句好了，但「更正一下，谁说……」反过来被删，「周三，不对，周四」中中档也不修了。退回。
- 改成在检查里拦（`Polish.problem`）：原文有「更正」「纠正」、模型的结果里没有，就用原文，日志记「删了「更正」，用原文」。

5 句 × 4 种组合 × 3 遍：带「更正」「纠正」的 3 句 36 次全留住；「周三，不对，周四」「可能是网络，哦，是权限的问题」和改前一样（中中档「周三」那句模型本来就时修时不修）。

## 四、接着说时补逗号

短句去掉末尾句号（设置里默认开）、或者识别本身没给标点时，接着说的下一句会直接粘在后面（日志里 17:47 微信那句，PM 手动在开头补了个「，」）。

**改法**：粘贴前读一下输入框里光标前的字（和改字记录用的同一套辅助功能接口），同时满足这几条就在这一句开头补「，」：

- 光标前的文字正好以上一句粘进去的字结尾（光标还跟在上一句后面；手打的、换了输入框的不管）；
- 上一句最后一个字是字母、汉字或数字（没标点）；
- 这一句第一个字也是字母、汉字或数字。

两边都是英文时补空格。读不到输入框的应用（没开辅助功能树的 Electron 第一次）就不补，和以前一样。设置「通用」里加了开关「接着说时补逗号」，默认开。日志记「上一句末尾没标点，开头补「，」」。

## 实测

- 当时的三段录音走完整流程（`--test-file`，带润色）：「更正一下，谁说轻量 Agent 的不能上网了？」「先更正一下，谁说清凉 Agent 的不能上网了？」（「清凉」是当时那一遍发音）「先更正一下，我觉得你是不是？」。
- `Signfix` 19 句（上表 + 「零下-20度」「C++1 版本」「v-1.2」这类不该动的）在 scratchpad 里跑过，全对。
- 补逗号没有写自动测试，PM 装上以后手动试过，说没问题。
