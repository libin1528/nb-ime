# NB 输入法 v0.2.1：Liquid Glass 胶囊 + 快捷键（两个、鼠标侧键）

2026-10-28。v0.2 之后 PM 提的几个小改进，服务端没动。

## 已拍的板（PM 2026-10-28）

- 录音胶囊改成 iOS 26/27 的 Liquid Glass：半透明、透出并折射背后的内容，状态切换时形状连续变形，任何背景上字都看得清。
- 玻璃**跟系统深浅**（另一个选项是一直深色玻璃，没选）。
- PM 嫌 regular 玻璃在纯白页面上看不出来，改成**更透的 clear + 垫一层薄底**。
- 快捷键可以设两个，效果一样；第二个可以不设。
- 快捷键支持鼠标侧键。
- 版本号 0.2.1。
- 识别后的「滤差 / 优化」两个润色方向（各有关 / 中 / 强，默认中）另开会话做，不在这一轮。

## 做完的情况

- 胶囊（`Sources/Capsule.swift`）：
  - 底子是系统的 `NSGlassEffectView`（macOS 26 起有），style `.clear`。
  - 圆角收起和展开都是 22，左下角圆钮离边 8，和外框同心；变形时只有长宽在变。
  - 出现时从底边中点的一颗圆长成胶囊，消失时缩回去。
  - 文字、图标用 `labelColor`，跟着玻璃深浅变。
- 快捷键（`Sources/Hotkey.swift`）：
  - `codes` 存一到两个键，按着的键放在 `held` 里：第一个按下才算开始，最后一个松开才算结束。
  - 鼠标侧键存成 `1000 + 按键号`，事件钩子多听 `otherMouseDown/Up`。设成快捷键的侧键吞掉，左右键不收。
- 配置：`config.json` 多一项 `hotkeyCode2`，没设就不写；老配置只有 `hotkeyCode` 时，第二个为空。
- 设置「快捷键」页改成两行：快捷键 / 第二个快捷键。两个设成同一个键时当场红字提示，不存。菜单第一行和首次引导都显示「按住 A 或 B 说话」。
- 调试：`NBIME --demo morph` 一次播完「长出来 → 展开 → 识别中 → 已输入 → 缩回」，录变形用。
- 对照图都在 `design/glass/`：
  - 改前改后 `capsule-{light,dark,wallpaper}.png`；
  - regular / clear / clear+薄底 `capsule-clear-*.png`；
  - 变形录屏 `capsule-morph.mp4`；
  - 快捷键 `hotkey-two.png`、`hotkey-mouse.png`。

## 坑

- `.clear` 玻璃不垫底时，系统浅色模式下，深色背景上的黑字发灰看不清。`tintColor` 几乎不起作用，最后在 `CapsuleView` 里自己垫一层反色薄底：浅色模式白 0.32，深色模式黑 0.28。
- 玻璃只能折射真实窗口：截图要在胶囊后面真的摆一个窗口。这次用的是 scratchpad 里临时写的 backdrop 小工具，没进仓库。
- `--demo` 用的是真实的 `config.json`。要截「设了第二个快捷键」的样子，得临时改配置，截完还原。截图时 PM 正好按热键的话，会把真胶囊也截进去，要重截。
- 拿 `-AppleInterfaceStyle Dark` 启动参数切不了深色，截深色模式时临时给面板设了 `darkAqua`。
- 事件钩子被系统停用（超时或系统输入保护）期间，松开事件会丢。之前 `held` 是单个布尔，下次按同一个键就自愈。设了两个键以后，丢了松开的那个会一直算「按着」，另一个键起不了录音。现在钩子重新打开后按实际按键状态对一遍（`resync()`），修饰键变化时也按标志位补上。
- 热键还是只能请 PM 亲手按，Claude 模拟的按键会被系统丢掉；`Hotkey.handle` 的逻辑可以在测试小程序里喂合成的 `CGEvent` 测。
